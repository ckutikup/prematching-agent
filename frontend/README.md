# Frontend

React and TypeScript interface for student intake, program recommendations, program details, and saved programs.

```sh
npm ci
npm run dev
```

The development server uses port 5173 and proxies `/api` to FastAPI on port 8000. See the [project README](../README.md) for backend and database setup.

`npm run lint` checks the source; `npm run build` produces `dist/` for the production server.
